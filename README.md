# リズムてんこもり

スマホのブラウザで遊べる、子ども向けのリズムゲーム集です。ボタン1つで遊べます。

**▶ あそぶ：https://ryocchi24.github.io/rythmgame/**

| ゲーム | あそびかた |
| --- | --- |
| けぬき名人 | ツルピカさんの頭に毛がリズムで生えてくる。「せーの！」のあと、同じリズムでボタンを押してプチッと抜く。くるくるの巻き毛は長押し。 |
| カラテねこ | 飛んでくる植木ばちやスイカを、ネコの前に来たタイミングでパンチ！ 1曲まるごと続けて遊ぶ。 |
| ケロっと わくぐり | 「パ・ピ・プ・ペ」の合図で輪が近づいてくる。仲間のカエルに続いて、「ポ！」でジャンプして輪をくぐる。 |

- 難易度は「かんたん／ふつう／むずかしい」。ハイスコアは難易度ごとに記録されます（その端末のブラウザに保存）。
- 「せってい」で、はやさ・長さを変えられます。
- iPhone はマナーモードだと音が出ません。

## 動かしかた

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。

スマホで試すときは、同じ Wi-Fi につないだ状態で次のようにして、表示されたアドレスをスマホで開きます。

```sh
npx serve .
```

## 公開（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります
